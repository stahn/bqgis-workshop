# Protokoły sieciowe

Zestawy reguł umożliwiające komunikację między urządzeniami w sieci.

## Kluczowe protokoły

| Protokół | Warstwa | Zastosowanie |
|----------|---------|-------------|
| TCP | Transportowa | Niezawodna transmisja |
| UDP | Transportowa | Szybka, bez gwarancji |
| IP | Sieciowa | Adresowanie i routing |
| HTTP/S | Aplikacji | Strony WWW |
| DNS | Aplikacji | Tłumaczenie nazw na IP |
| SMTP | Aplikacji | Poczta elektroniczna |
| WebSocket | Aplikacji | Komunikacja dwukierunkowa |

## TCP vs UDP

- **TCP**: wolniejszy, ale gwarantuje dostarczenie (strony WWW, pliki)
- **UDP**: szybszy, brak gwarancji (gry online, streaming wideo)

## HTTP/2 i HTTP/3

Nowsze wersje HTTP umożliwiają multipleksowanie i kompresję nagłówków — znacznie szybsze ładowanie stron.
