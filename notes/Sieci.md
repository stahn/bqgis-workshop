# Sieci komputerowe

Systemy umożliwiające komunikację i wymianę danych między urządzeniami.

## Główne tematy

- [[Internet]] — globalna sieć sieci
- [[Protokoly]] — języki komunikacji sieciowej

## Model OSI — 7 warstw

1. Fizyczna — bity, kable, sygnały
2. Łącza danych — MAC, Ethernet
3. Sieciowa — IP, routing
4. Transportowa — TCP, UDP
5. Sesji — zarządzanie połączeniami
6. Prezentacji — kodowanie, szyfrowanie
7. Aplikacji — HTTP, FTP, SMTP

## Typy sieci

- **LAN** — sieć lokalna (biuro, dom)
- **WAN** — rozległa (kraj, kontynent)
- **PAN** — osobista (Bluetooth)
