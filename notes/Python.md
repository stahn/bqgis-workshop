# Python

Język programowania wysokiego poziomu, stworzony z myślą o czytelności kodu.

```python
def powitanie(imie: str) -> str:
    return f"Cześć, {imie}! Witaj w świecie Pythona."

print(powitanie("Obsidian"))
```
