# Algebra

Dział matematyki zajmujący się strukturami abstrakcyjnymi: grupami, pierścieniami, ciałami.

## Kluczowe pojęcia

- Równania liniowe i kwadratowe
- Macierze i wyznaczniki
- Przestrzenie wektorowe
- Grupy i homomorfizmy

## Zastosowania

Kryptografia, grafika komputerowa, uczenie maszynowe — algebra jest wszędzie.

## Wzór na rozwiązanie równania kwadratowego

```
ax² + bx + c = 0
x = (-b ± √(b²-4ac)) / 2a
```
